# Engenharia de Software: Totem de Autoatendimento

Relatório técnico da disciplina de Engenharia de Software da FATEC, elaborado por Gabriel Muzel e Mateus Iuri sob orientação da Profa. Dra. Suéllen Martinelli.

O projeto investiga um totem de autoatendimento para restaurantes de cidades pequenas, com foco em reduzir filas e melhorar a experiência do cliente, incluindo acessibilidade e atendimento híbrido.
